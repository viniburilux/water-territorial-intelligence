# Baía de Todos os Santos

**WTI capability:** regional territorial comparison.

This fixture preserves the documented scale: 33,600 embeddings, 64 dimensions, eight territories and 2018–2024 STT comparison. STT is not automatically hydrological degradation.

The machine-readable observation is in `observation.json`. It is processed by `demo/run_demo.py` through the same offline adapter used by the other cases.
