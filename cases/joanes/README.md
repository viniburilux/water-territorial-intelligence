# Rio Joanes

**WTI capability:** signal → hotspot → coordinate → SAR/NDVI → historical visual investigation.

The public GhostWorks consolidated case data documents Rio Joanes at -12.8176, -38.3315 and separates it from the refinery-centered 5 km study area. The P03 label comes from the internal GhostWorks-ESG case record, not the public repository.

The machine-readable observation is in `observation.json`. It is processed by `demo/run_demo.py` through the same offline adapter used by the other cases.

## Source traceability

The public GhostWorks repository documents the coordinate and qualitative finding of water-body alteration on the Rio Joanes (`consolidated_data.md`, Case 01). The P03 label and numeric values in `observation.json` (SAR +7.19 dB, NDVI -0.741, hotspot score 0.501) are recorded in the internal GhostWorks-ESG case record; that primary artifact has not yet been redistributed in a public repository.

The numbers are preserved with their documentary origin rather than removed: traceability, not suppression. Publishing a redistributable extract of the primary artifact is on the [roadmap](../../docs/roadmap.md).
