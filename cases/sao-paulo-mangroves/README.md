# São Paulo mangrove coastline

**WTI capability:** ecosystem-scale multi-source temporal intelligence.

This executable fixture preserves the documented aggregate dossier: approximately 4,000 points, nine coastal municipalities, 20 AuditLab alerts and four temporal imagery epochs. It does not fabricate point coordinates or raw metrics.

The machine-readable observation is in `observation.json`. It is processed by `demo/run_demo.py` through the same offline adapter used by the other cases.
